# ایلام زیبا — GitHub Pages

نسخه وب استاتیک و واکنش‌گرای پروژه «ایلام زیبا» برای انتشار رایگان در GitHub Pages.

## انتشار
1. در GitHub یک Repository بسازید، مثلاً `ilam-ziba`.
2. فایل‌های این پوشه را Upload کنید.
3. Settings → Pages → Deploy from a branch را انتخاب کنید.
4. Branch = `main` و Folder = `/ (root)` سپس Save.
5. آدرس سایت معمولاً `https://USERNAME.github.io/ilam-ziba/` خواهد بود.

## بانک اطلاعاتی
GitHub Pages دیتابیس قابل‌نوشتن ندارد. فرم فعلی برای دمو، اطلاعات را در localStorage مرورگر ذخیره می‌کند. برای دیتابیس واقعی، Firebase یا Supabase را متصل کنید.
